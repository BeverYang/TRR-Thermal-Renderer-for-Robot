# 展示素材与来源

`demos/` 为五个场景的现行参考控制视频及封面，文件摘要、分辨率、时长和来源见 [媒体清单](demos/manifest.json)。轨道维修使用用户暂时验收通过的 90 秒版本，未使用此前被拒绝的视频。

- 机器人模型来源：[MuJoCo Menagerie](https://github.com/google-deepmind/mujoco_menagerie)。
- 月面纹理来源：[Poly Haven Moon 01](https://polyhaven.com/a/moon_01)。
- 轨道维修历史依据：[NASA Skylab 首次维修出舱](https://www.nasa.gov/history/skylab-2-first-repair-spacewalk/)。机器人加热过程为工程改编。
- `thermal-history-demo.gif`：640×300、46.8 秒原始加速演示。
- `thermal-history-demo.mp4`：从原 GIF 第 10—38 秒截取的 28 秒桌面版，640×180，移除底部参数与曲线。
- `thermal-history-mobile.mp4`：同节选的 212×360 手机版，将 RGB 与全景热观测上下排列。
- `thermal-history-poster.jpg`、`thermal-history-mobile-poster.jpg`：对应视频关键帧封面。
- `flow-rgb.png`、`flow-thermal.png`：从同一真实输出帧裁出的首屏同步观测小图。
- `thermal-interaction-sequence.png`：转运、再抓持、冷却的 RGB/温度序列原图。
- `thermal-interaction-sequence-dark.png`：当前页面使用的深色版，仅调整图外背景与文字颜色，RGB、热图和色标保持原色。
- `trr-overview.png`：原有技术总览；`rgbt-backends.png`：两后端成像示例。
- `trr-logo.png`：TRR 热手印标志；机构标志沿用既有素材。

派生核心视频保持原 GIF 的清晰度，没有放大、锐化或冒充原始高清渲染。原有图像、模型、纹理与标志的作者版权及各自许可保持不变。本清单不将第三方素材重新声明为统一开源许可。网页视频不等同于产线验证或策略实机成功率。
