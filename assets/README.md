# 展示素材与来源

`demos/` 为五个新增场景的现行参考控制视频及从视频抽取的封面，文件摘要见 [媒体清单](demos/manifest.json)。轨道维修使用用户暂时验收通过的90秒版本，未使用此前被拒绝的视频。

- 机器人模型来源：[MuJoCo Menagerie](https://github.com/google-deepmind/mujoco_menagerie)。
- 月面纹理来源：[Poly Haven Moon 01](https://polyhaven.com/a/moon_01)。
- 轨道维修历史依据：[NASA Skylab 首次维修出舱](https://www.nasa.gov/history/skylab-2-first-repair-spacewalk/)。机器人加热过程为工程改编。
- `thermal-history-demo.gif`：热工件转移和接触余热的加速演示。
- `thermal-interaction-sequence.png`：转运、再抓持、冷却的RGB/温度序列。
- `trr-overview.png`：原有技术总览；`rgbt-backends.png`：两后端成像示例。
- `trr-logo.png`：TRR热手印标志；机构标志沿用既有素材，`chizhi-brand.png` 为重排中英文并去除底部宣传语的炽智标志。

原有图像、模型、纹理与标志的作者版权及各自许可保持不变。本清单不将第三方素材重新声明为统一开源许可。网页视频不等同于产线验证或策略实机成功率。
